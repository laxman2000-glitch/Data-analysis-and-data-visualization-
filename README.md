# Walmart Customer Marketing Data Analysis

## Project Overview

This project analyzes customer marketing data using Python to understand customer demographics, purchasing behavior, product performance, shopping preferences, and marketing campaign acceptance.

The project applies data cleaning, missing-value imputation, feature engineering, exploratory data analysis (EDA), data visualization, and statistical hypothesis testing to identify patterns and generate business insights.

## Objectives

* Clean and preprocess customer marketing data.
* Handle missing income values using education and marital status groups.
* Analyze customer age, income, family size, and spending behavior.
* Identify top-performing and low-performing product categories.
